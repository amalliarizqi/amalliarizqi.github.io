Saya merupakan lulusan Program Studi Matematika, Universitas Negeri Yogyakarta, yang memiliki ketertarikan untuk mengembangkan karier di bidang analisis data.

Melalui pengalaman di Badan Pusat Statistik (BPS), saya terbiasa melakukan input, pemeriksaan, dan pengolahan data secara teliti. Pengalaman tersebut mengajarkan saya pentingnya kualitas data sebelum digunakan untuk analisis.

Saat ini, saya terus mengembangkan keterampilan SQL, Microsoft Excel, dan Python melalui pembelajaran mandiri serta pengerjaan proyek portofolio.
